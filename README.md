# Personal website of Himanshu Gupta

Plain HTML and CSS. No build step. Photo and CV are included.

## Publish on GitHub Pages

1. On GitHub, create a new public repository named exactly `Himanshugupta23.github.io`.
2. Click "uploading an existing file" and drag in all files from this folder. Commit.
3. Go to Settings, then Pages. Choose "Deploy from a branch", branch `main`, folder `/ (root)`. Save.
4. After a minute or two the site is live at https://himanshugupta23.github.io

## Updating later

Open any `.html` file on GitHub, click the pencil icon, edit, and commit.
To replace the CV, upload a new file named `cv.pdf`.
